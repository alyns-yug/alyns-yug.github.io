# Сайт завода металлообработки

## Что где лежит

| Файл | Что в нём | Как часто менять |
|---|---|---|
| `js/config.js` | Название, телефон, Telegram, почта, адрес, координаты для карты | Здесь меняется всё основное |
| `index.html` | Тексты, услуги, блок «Наши работы» | Когда меняете тексты или добавляете фото |
| `css/style.css` | Цвета и оформление (цвета — в самом верху файла) | Редко |
| `images/` | Логотип и фото работ | Добавляете файлы сюда |
| `js/main.js` | Служебный код (меню, карты) | Не трогать |

## Как выложить сайт в интернет через GitHub (бесплатно)

### 1. Регистрация
1. Зайдите на https://github.com и нажмите **Sign up**.
2. Придумайте имя пользователя, например `zavod-metall`. От него зависит временный адрес сайта: `zavod-metall.github.io`.

### 2. Создаём хранилище (репозиторий)
1. Справа вверху нажмите **+** → **New repository**.
2. В поле **Repository name** напишите ровно: `ВАШЕ-ИМЯ.github.io`, например `zavod-metall.github.io`.
3. Выберите **Public** и нажмите **Create repository**.

### 3. Загружаем файлы сайта
1. На странице репозитория нажмите ссылку **uploading an existing file**.
2. Распакуйте архив с сайтом на компьютере и **перетащите в окно браузера всё содержимое папки** (`index.html`, папки `css`, `js`, `images` и остальное), а не саму папку.
3. Внизу нажмите зелёную кнопку **Commit changes**.

### 4. Включаем сайт
1. В репозитории откройте **Settings** → слева **Pages**.
2. В разделе **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
3. Через 1–2 минуты сайт откроется по адресу `https://ВАШЕ-ИМЯ.github.io`.

## Подключаем свой домен (например, zavod-metall.ru)

### 1. Покупаем домен
Домен в зоне .ru покупается у любого регистратора: REG.RU, RU-CENTER (nic.ru), Timeweb и других. Стоит около 200–1000 ₽ в год.

### 2. Настраиваем DNS у регистратора
В личном кабинете регистратора откройте **Управление DNS** (оно может называться «DNS-записи» или «Зона DNS»). Удалите старые записи типа A для `@`, если они есть, и добавьте новые:

| Тип | Имя (хост) | Значение |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | ВАШЕ-ИМЯ.github.io. |

### 3. Указываем домен в GitHub
1. Откройте **Settings → Pages**, в поле **Custom domain** впишите `zavod-metall.ru` и нажмите **Save**.
2. Подождите. Обновление DNS занимает от 15 минут до 24 часов.
3. Когда проверка пройдёт, поставьте галочку **Enforce HTTPS**, чтобы сайт открывался с замочком.

## Как вносить изменения

**Через браузер (проще всего):**
1. Откройте нужный файл в репозитории, например `js/config.js`.
2. Нажмите карандаш ✏️ (**Edit**), исправьте текст и нажмите **Commit changes**.
3. Через 1–2 минуты изменения появятся на сайте.

**Добавить фото работ:**
1. Откройте папку `images` → **Add file → Upload files** и загрузите фото. Название файла пишите латиницей, например `laser-1.jpg`.
2. В `index.html` найдите блок «Наши работы» и замените `<div class="work__img"></div>` на
   `<img class="work__img" src="images/laser-1.jpg" alt="Лазерная резка">`

**Добавить логотип:**
1. Загрузите файл логотипа в `images`, например `logo.svg` или `logo.png`.
2. В `index.html`, в самом верху, замените строку `<span class="logo__mark" aria-hidden="true"></span>` на
   `<img src="images/logo.svg" alt="Логотип">`

> Совет: фото перед загрузкой лучше уменьшить до ~1600 px по ширине, тогда сайт будет быстро открываться.
